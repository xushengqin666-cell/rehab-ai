# 康复AI · 云端同步上线指南（3 步，全端自动同步）

> 目标：用户在任意一台设备登录同一账号，训练/评估数据自动同步；换设备登录即恢复。
> 现状：App 内的注册/登录/自动同步/冲突合并/注销账号代码**都已具备**，只差把后端地址与密钥填进去。

## 第 1 步：建后端（约 3 分钟）
1. 打开 https://supabase.com → 注册/登录 → New project（Region 选新加坡或东京，国内访问更快）。
2. 项目建好后进 **SQL Editor → New query**，把仓库里 `supabase/schema.sql` 的**全部内容**粘进去 → **Run**。
   - 这一步会建 `userdata` 表、打开**行级权限**（否则拿到公开密钥的人能读别人数据）、并创建注销账号用的 `delete_my_account()` 函数。
3. 进 **Project Settings → API**，复制两个值：`Project URL`、`anon public` key（这个是可以公开的，客户端要用）。

## 第 2 步：填进 App（1 分钟）
打开 `app.js`，找到（约 2034 行）：

```js
const CLOUD_HARDCODED = null;
```

改成：

```js
const CLOUD_HARDCODED = { url: 'https://你的项目.supabase.co', anonKey: '你的 anon key' };
```

改完这一处，**所有用户**打开 App 就能注册登录并自动同步，用户界面里不会出现任何配置项。

## 第 3 步：验证（2 分钟）
```powershell
powershell.exe -ExecutionPolicy Bypass -File tests\start-servers.ps1
node tests/cloud-e2e.mjs
```
会自动跑完「设备A 注册并上云 → 清空本机模拟换设备 → 设备B 登录拉回数据 → 注销账号」全流程，逐项打印 OK/FAIL。

## 上架前必须确认的合规项
- [x] 隐私政策已如实声明云端存储（不再写「不上传任何服务器」）
- [x] 设置页有「注销账号」，会连云端账号与云端数据一起永久删除（应用商店硬要求）
- [x] 退出登录可随时停止同步
- [ ] Supabase 项目所在地与隐私政策一致（建议写明新加坡/东京机房）
- [ ] 上架材料里的隐私政策网址 = 线上 privacy 页面

## 备用方案（不想用 Supabase）
本机已装 wrangler（Cloudflare），可用自家 Worker + D1 自建同款接口（家庭药师项目就是这套）。
需要先执行 `wrangler login`（会开浏览器授权），之后我可以照 `家庭药师-web/worker` 的现成模式搭一个 rehab-sync 后端并部署。
