# 康复AI · 火柴人姿势分析（Web 版 v2.2 · 中英双语）

手机 + 电脑通用的响应式 Web App：浏览器实时摄像头 → AI 姿态识别 → **火柴人骨架**
动作分析，集成记录打卡、自我评估、理疗预约、**自定义动作**、**数据采集训练闭环**。
视频不上传，AI 与数据全在本地运行。**中英双语，自动检测浏览器语言，一键切换。**

## 🌍 线上版（直接发给别人用）
**https://xushengqin666-cell.github.io/rehab-ai/**
（手机浏览器打开即可用摄像头；桌面二维码：`康复AI-线上网址二维码.png`）

## 支持的动作（火柴人实时分析 + 自动计数）
| 动作 | 分析指标 | 数据标签（采集用） |
|------|---------|-------------------|
| 🦵 深蹲 | 膝盖角 / 前倾 / 深度 / **膝盖内扣** | good/shallow/deep/lean/valgus |
| 🚶 弓步蹲 | 前膝角 / 后膝角 / 前倾 | good/frontShallow/frontDeep/lean |
| 💪 俯卧撑 | 肘角 / 身体直线度 | good/shallow/sag |
| ⭐ **自定义** | 自己定角度、合格范围、计数规则、提示语 | good/bad |

## 快速开始（本机）
```bash
python serve.py
```
浏览器打开 `http://127.0.0.1:8000`（电脑可开摄像头；手机同 Wi-Fi 可访问，摄像头需 HTTPS）

## 真实数据训练闭环（科研项目核心）
1. 训练页点「📝 数据采集」→ 选动作 → 摆姿势 → 点标签（每类 ≥50 条）
2. 设置页「导出采集 CSV」
3. 电脑上运行（Python 侧，rehab-ai 文件夹）：
   ```bash
   python train_from_web.py 康复AI采集数据-日期.csv
   ```
   → 按动作自动训练 RandomForest，输出交叉验证准确率 + `model_<动作>.pkl`

## 目录结构
| 文件 | 说明 |
|------|------|
| index.html | 单页应用（训练/记录/评估/日程/设置） |
| style.css | 移动端优先响应式样式 |
| app.js | 主逻辑：火柴人绘制、采集、记录、评估、日程、自定义管理 |
| analysis.js | **动作引擎**：角度数学 + 深蹲/弓步蹲/俯卧撑/自定义分析 |
| i18n.js | **中英双语词典** + 语言切换 + 浏览器语言自动检测 |
| pose_landmarker_full.task | AI 姿态模型（本地，不上传） |
| vision_bundle.mjs + wasm/ | MediaPipe 浏览器运行时（本地，离线可用） |
| vendor/ | 二维码编解码库（jsQR / qrcode-generator，MIT，本地运行） |
| serve.py | 局域网启动器（打印手机访问地址） |
| deploy.bat | 一键部署准备（git 提交 + 上线说明） |
| netlify.toml | Netlify 部署配置 |

## 技术说明
- AI：MediaPipe PoseLandmarker（WebAssembly，本地运行）
- 判定阈值与 Python 版 rehab-ai 一致，可在 analysis.js 顶部调整
- 数据：浏览器 localStorage；导出 JSON 备份 / CSV 训练数据
